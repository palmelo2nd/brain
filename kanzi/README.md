# 漢字学習アプリ

小学校配当漢字（学年別）を、読みクイズ・意味熟語クイズ・フラッシュカードで学習できるWebアプリ。HTML+CSS+JavaScript（バニラJS、ESモジュール）で構築し、[Second Brain](../brain/README.md)と同様にGitHub Pages想定・GitHubリポジトリへのデータ保存に対応する。

## 1. 対象漢字・データ構成

小学校で習う学年別配当漢字（1年〜6年、1006字）を収録。各漢字は「学年」「画数」「音読み」「訓読み」「意味」「熟語（2件程度）」を持つ。

漢字そのもののデータ（読み・意味・熟語）はユーザーごとに変わらないため、`data/kanjiMaster.json`としてアプリ本体（コードリポジトリ）に同梱している。学習の進捗（出題回数・正解回数など）だけを、Second Brainと同じデータリポジトリ（`palmelo2nd/brain_data`の`kanzi/data.md`）にGitHub API経由で保存する。この分離の理由は[CLAUDE.md](./CLAUDE.md)の「2. データの分離方針」を参照。

現時点では、日本語の「意味」「熟語」は小学1年（80字）のみ人手で入力済み。学年2〜6は音読み・訓読みのみで、意味・熟語クイズは対象外（[8章](#8-既知の制約今後の拡張候補)参照）。

## 2. 学年の選択

画面上部の「対象学年」プルダウンで、すべて（1〜6年）または学年を1つ選ぶ。選択はホーム・各クイズ・フラッシュカード・成績のすべてのタブに共通で適用され、切り替えると出題中の問題やカードは作り直される。

## 3. 読みクイズ

漢字を1字表示し、音読み・訓読みのどちらかを4択で答える。出題は、進捗が悪い（正答率が低い）漢字・未学習の漢字ほど選ばれやすい重み付き抽選（`js/modules/progress.js`の`calcWeight`）で行う。回答すると正誤と正解を表示し、「次の問題」で次へ進む。

## 4. 意味・熟語クイズ

漢字の意味を4択で当てる問題と、熟語の空欄（例：「＿番」）に入る漢字を4択で当てる問題を、ランダムに出し分ける。意味・熟語データがある漢字（現状は小学1年）のみが対象。対象漢字が4字未満の学年を選ぶと、その旨のメッセージを表示する。

## 5. フラッシュカード

対象学年から重み付き抽選で最大20枚のカードを作り、1枚ずつ表示する。カードをタップ／クリックすると裏面（音読み・訓読み・意味）が出て、「もう一度」「覚えた」で自己採点する（この自己採点も進捗に反映される）。最後まで進むと「最初からやり直す」で新しいセットを作れる。

## 6. 成績

対象学年内の学習済み字数・平均正答率と、正答率が低い（かつ一定回数以上出題済みの）「苦手な漢字」を最大20件、正答率の低い順に表示する。

## 7. 設定・データの保存

GitHub Personal Access Token（Contents権限、`palmelo2nd/brain_data`への読み書きが必要）を入力し、「読み込み」で進捗をGitHubから取得、「保存」でLocalStorageとGitHubの両方に反映する。

- クイズ・フラッシュカードで1問答えるたびに、進捗はLocalStorageへ即座に保存される（オフラインでも進捗は失われない）。GitHubへの反映は「保存」ボタンを押したときのみ行われる。
- 保存時にGitHub側が別端末等で更新されていた場合（409エラー）は、その旨を表示するので「読み込み」で最新化してから再保存する。

## 8. 既知の制約・今後の拡張候補

- 学年2〜6の「意味」「熟語」データが未入力（読みクイズ・フラッシュカードの音訓表示は全学年で利用可能）。追加する際は`code/kanzi/data/kanjiMaster.json`を辞書等で確認しながら直接編集する（詳細は[CLAUDE.md](./CLAUDE.md)）。
- 2020年度改訂で追加された都道府県名関連の20字（茨・栃・埼・岡・阪など）は未収録（出典データが改訂前の1006字ベースのため）。
- 書き取り（手書き入力）モードは未実装。
